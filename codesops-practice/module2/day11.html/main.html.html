Here are the answers to your questions: ▎Q1: What is the difference between a client and a server? • Client: A client is a device or application that requests services or resources from a server. Clients can be web browsers, mobile apps, or any other software that communicates with a server to retrieve data or perform actions. • Server: A server is a system that provides resources, data, or services to clients over a network. Servers respond to client requests and can host websites, databases, applications, and more. ▎Q2: What does DNS do, and why is it needed? • DNS (Domain Name System): DNS translates human-readable domain names (like www.example.com) into IP addresses (like 192.0.2.1) that computers use to identify each other on the network. • Why it's needed: DNS is essential because it allows users to access websites using easy-to-remember names instead of having to remember numerical IP addresses. It simplifies navigation on the internet. ▎Q3: What is the difference between HTTP and HTTPS? • HTTP (Hypertext Transfer Protocol): HTTP is an application protocol used for transmitting hypertext via the internet. It does not include any encryption, which means data sent over HTTP can be intercepted and read by third parties. • HTTPS (HTTP Secure): HTTPS is the secure version of HTTP. It uses encryption (typically via SSL/TLS) to protect the data transmitted between the client and server, ensuring confidentiality and integrity. This is particularly important for sensitive transactions, such as online banking or shopping. ▎Q4: Name three stages the browser goes through to render a page. 1. Parsing HTML: The browser reads the HTML document and constructs the Document Object Model (DOM), which represents the structure of the web page. 2. Constructing CSSOM: The browser processes CSS files and styles embedded in HTML to create the CSS Object Model (CSSOM), which defines how elements should be styled. 3. Rendering: The browser combines the DOM and CSSOM to create a render tree, which it then uses to layout the page and paint pixels onto the screen. ▎Q5: What goes in the versus the of a document? • : The section contains meta-information about the document, such a – Title of the page () – Links to stylesheets (<link>) – Scripts (<script>) – Meta tags (for SEO, character set, viewport settings, etc.) • <body>: The <body> section contains the actual content of the webpage that will be displayed to users, such as: – Text – Images – Videos – Forms – Other interactive elements ▎Q6: Why use <header> and <nav> instead of plain <div> elements? • Semantic Meaning: Using semantic elements like <header> and <nav> provides meaning to the structure of the document. This helps search engines and assistive technologies understand the content better. • Accessibility: Semantic elements improve accessibility for screen readers and other assistive technologies by providing context about the type of content contained within them. • SEO Benefits: Search engines may give more weight to semantic elements when indexing pages, potentially improving search rankings. Using semantic HTML enhances both user experience and code maintainability by making it clearer what each part of your document represents.
